================================================================================
RENDER — STATIC SITE
================================================================================

A) RECOMMENDED — Root Directory = EMPTY (repo root). Matches render.yaml + root render-build.sh

    Build Command:
        npm install && sh render-build.sh

    Publish directory:
        client/dist

    (Uses ./render-build.sh at the repo root — it cd's into client/ and runs Vite only.)

--------------------------------------------------------------------------------

B) If Root Directory = "client" (advanced)

    Build Command:
        npm install && sh render-build.sh

    Publish directory:
        dist

    (Uses ./client/render-build.sh — the same filename under client/.)

--------------------------------------------------------------------------------

NEVER append:  && npx prisma migrate deploy
That belongs ONLY to the API service (Root Directory "server").

--------------------------------------------------------------------------------
C) If you use a Web Service (Node) instead of Static Site — Root Directory "client"

    Build Command:  npm install && npm run build
    Start Command:  npm start

    (package.json "start" serves ./dist with `serve`. Render sets PORT automatically.)

    Prefer Static Site (CDN) when possible — no start command needed.

================================================================================
